# 🌍 i18n — Internationalisation (Français + Anglais)

## Package

| Package | Version | Rôle |
|---------|---------|------|
| `@nuxtjs/i18n` | 10.4.0 | Internationalisation complète pour Nuxt |

## Installation

```bash
bun add @nuxtjs/i18n
```

## Configuration

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    strategy: 'prefix_except_default', // /fr/... et / pour le défaut
    defaultLocale: 'fr',              // Français = langue par défaut
    lazy: true,                       // Chargement paresseux des traductions
    restructureDir: '',               // Désactive le dossier i18n/ par défaut
    langDir: 'locales',               // Fichiers de traduction dans locales/
    locales: [
      { code: 'fr', iso: 'fr-FR', name: 'Français', file: 'fr.json' },
      { code: 'en', iso: 'en-US', name: 'English', file: 'en.json' },
    ],
    detectBrowserLanguage: {
      useCookie: true,
      cookieKey: 'i18n_redirected',
      redirectOn: 'root',
    },
    seo: true, // Balises hreflang automatiques
  },
})
```

## Fichiers de traduction

Situés dans `locales/` à la racine du projet :

| Fichier | Langue |
|---------|--------|
| `locales/fr.json` | Français |
| `locales/en.json` | Anglais |

### Structure

```json
{
  "app": { "name": "Mon Application" },
  "nav": { "home": "Accueil", "dashboard": "Tableau de bord" },
  "auth": { "login": "Connexion", "email": "Email" },
  "dashboard": { "welcome": "Bonjour {name}" },
  "errors": { "notFound": "Page introuvable" },
  "common": { "save": "Enregistrer", "cancel": "Annuler" },
  "language": { "fr": "Français", "en": "English", "switch": "Changer de langue" }
}
```

## Utilisation dans les composants

```vue
<script setup lang="ts">
const { t, locale, setLocale } = useI18n()

function toggleLocale() {
  setLocale(locale.value === 'fr' ? 'en' : 'fr')
}
</script>

<template>
  <!-- Traduction simple -->
  <h1>{{ t('app.name') }}</h1>

  <!-- Avec interpolation -->
  <p>{{ t('dashboard.welcome', { name: user?.name }) }}</p>

  <!-- Switch de langue -->
  <UiButton @click="toggleLocale">
    {{ locale === 'fr' ? '🇫🇷 FR' : '🇬🇧 EN' }}
  </UiButton>
</template>
```

## URLs générées

| Locale | Exemple d'URL |
|--------|--------------|
| Français (défaut) | `https://monsite.fr/admin` |
| Anglais | `https://monsite.fr/en/admin` |

## Désactiver / Supprimer

| Action | Étapes |
|--------|--------|
| Désactiver | Retirer `@nuxtjs/i18n` des `modules` + remplacer `t('...')` par du texte en dur |
| Supprimer | `bun remove @nuxtjs/i18n` + supprimer `locales/` |
